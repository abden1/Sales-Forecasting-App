Technical Notes

Data Preprocessing

The model uses the following feature engineering techniques:

  • Time-based features (day of week)
  • Lag features (previous day's sales, same day last week)
  • Rolling statistics (3-day moving average)
Validation Strategy

The model was validated using a time series split with the most recent 20% of data as the test set.

Potential Improvements
  • Include external factors (holidays, promotions, etc.)
  • Experiment with different algorithms (XGBoost, LSTM)
  • Implement hyperparameter tuning
