API Documentation

Integrate the Random Forest sales prediction model into your applications

API Overview

The Sales Prediction API provides programmatic access to the Random Forest model.

Base URL: http://localhost:5000

Features:

  • Single day prediction
  • Multi-day forecast (up to 30 days)
  • JSON response format
  • Error handling

Rate Limits:

  • 60 requests per minute
  • 1000 requests per day

Authentication

Currently, the API does not require authentication.

For production use, API keys should be implemented for security.

Coming Soon: API key authentication for secure access.

Single Prediction Endpoint

Endpoint
POST /api/v1/predict
Request Body Parameters
Parameter Type Required Description
lag_1 Number Yes Previous day's sales amount
lag_7 Number Yes Sales amount from 7 days ago
rolling_3_mean Number Yes Average sales of the past 3 days
day_of_week Integer (0-6) Yes Day of the week (0=Monday, 6=Sunday)
Example Request
{
  "lag_1": 525000,
  "lag_7": 510000,
  "rolling_3_mean": 505000,
  "day_of_week": 2
}
Example Response
{
  "success": true,
  "prediction": 535876.45,
  "prediction_formatted": "₹535876.45"
}

Multi-Day Forecast Endpoint

Endpoint
POST /api/v1/forecast
Request Body Parameters
Parameter Type Required Description
lag_1 Number Yes Most recent day's sales amount
lag_7 Number Yes Sales amount from 7 days ago
rolling_3_mean Number Yes Average sales of the past 3 days
day_of_week Integer (0-6) Yes Starting day of the week (0=Monday, 6=Sunday)
days Integer No Number of days to forecast (default: 7, max: 30)
Example Request
{
  "lag_1": 525000,
  "lag_7": 510000,
  "rolling_3_mean": 505000,
  "day_of_week": 2,
  "days": 3
}
Example Response
{
  "success": true,
  "forecast": [
    {
      "day": 1,
      "day_of_week": 2,
      "day_name": "Wednesday",
      "prediction": 535876.45,
      "prediction_formatted": "₹535876.45"
    },
    {
      "day": 2,
      "day_of_week": 3,
      "day_name": "Thursday",
      "prediction": 548921.32,
      "prediction_formatted": "₹548921.32"
    },
    {
      "day": 3,
      "day_of_week": 4,
      "day_name": "Friday",
      "prediction": 612045.78,
      "prediction_formatted": "₹612045.78"
    }
  ]
}
Error Response
{
  "success": false,
  "error": "Missing required field: lag_1"
}
Python Integration Example
import requests
import json

# Prepare prediction data
data = {
    "lag_1": 525000,
    "lag_7": 510000,
    "rolling_3_mean": 505000,
    "day_of_week": 2,
    "days": 7
}

# Make API request
response = requests.post('http://localhost:5000/api/v1/forecast', 
                        json=data)

# Process response
if response.status_code == 200:
    forecast = response.json()
    if forecast['success']:
        for day in forecast['forecast']:
            print(f"Day {day['day']} ({day['day_name']}): {day['prediction_formatted']}")
    else:
        print(f"Error: {forecast['error']}")
else:
    print(f"HTTP Error: {response.status_code}")
